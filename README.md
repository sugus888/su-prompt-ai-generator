# Su Prompt Ai Generator

โปรแกรมช่วยสร้าง prompt สำหรับงานเฟอร์นิเจอร์ — เลือกจากการ์ด แล้วคัดลอกไปวางใน AI ได้ทันที

- **ภาพเรนเดอร์**: ChatGPT, Nano Banana (Gemini)
- **เพลงประกอบ (บรรเลงล้วน)**: Gemini (Lyria), Suno, ElevenLabs, Stable Audio
- **คลิปวิดีโอ**: Gemini Omni, Kling, Runway, Luma, Hailuo, Wan

## ติดตั้ง

ดาวน์โหลด `SuPromptAiGenerator_<เวอร์ชัน>_x64-setup.exe` จากหน้า [Releases](https://github.com/sugus888/su-prompt-ai-generator/releases/latest) แล้วดับเบิลคลิก (Windows 10/11, ไม่ต้องใช้สิทธิ์ admin)

โปรแกรมตรวจอัปเดตจากหน้านี้เองทุกครั้งที่เปิด
